# 🎙️ Roster AI Assistant

Roster is an AI-powered desktop voice assistant built with Python.
git clone https://github.com/shamikghosh187-ux/Roster-AI.git
cd Roster-AI-Assistant
## ✨ Features

- 🎤 Voice command recognition
- 🧠 AI-powered conversations
- 👁️ Screen vision and screenshot analysis
- 🖥️ Open desktop applications
- 🔎 Google search
- ▶️ YouTube playback
- 💬 WhatsApp messaging
- 🔊 Text-to-speech responses

## 🛠️ Technologies

- Python
- Groq API
- Whisper
- NumPy
- SciPy
- SoundDevice
- PyAutoGUI
- Pyttsx3
- PyWhatKit

## 🔐 Security

Roster uses the `GROQ_API_KEY` environment variable.

Never expose your API key in the source code or upload it to GitHub.
